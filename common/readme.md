# `common/` — the bounded-context specification surface
`common/` holds the repo's **packages** as domain specifications (`common/<pkg>/readme.md`) and shared cross-cutting helpers. Running code lives in `apps/backend/src/<pkg>` and `apps/frontend/src/lib/<pkg>`.
## The package model in a paragraph
`common/<pkg>/readme.md` is the domain specification surface; the apps hold the **implementations**. Placement in the five-layer topology (`meta` < `infra` < `middleware` < `domain` < `app`) is owned by `common/meta/base/layering.py` (`PACKAGE_LAYER`), fixing a down-only dependency DAG. Internally a package converges into three **layers** — `base` (pure core, no I/O) / `extension` (impure cross-package edges) / `data` (read-model sink) — and publishes its public API via `__init__.__all__`. Structural gates (`tools/check_app_boundary.py`, `tools/check_base_purity.py`, `tools/check_tier_imports.py`, `tools/check_public_orm_exports.py`) enforce layering, purity, tier separation, and ORM boundaries without maintaining per-test contract mirrors.
