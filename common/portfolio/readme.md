# `portfolio` — Investment Position Accounting

Owns position quantities, cost basis (`FIFO`/`LIFO`/`AVGCOST` via `InvestmentLot`), `ManagedPosition` (`orm/portfolio.py`), `InvestmentTransaction`, and `DividendIncome` (`apps/backend/src/portfolio/`). Composes `ledger.post_entry` for double-entry cash/P&L entries and `pricing.resolve` for market valuations (never stores market prices or FX rates directly).

## Services & Reconciliation

- **Write (`extension/accounting.py`)**: `InvestmentAccountingService` exposes `post_buy`, `post_sell`, `post_dividend` using `TradeOrder`, `TradeAccounts`, and `DividendEvent`, ensuring open quantity `>= 0` and deterministic `source_type=system` entries (`common/audit/readme.md#source-type-trust-hierarchy-provenance`).
- **Atomic -> Managed (`extension/positions.py`)**: Windowed latest `AtomicPosition` per `(asset_identifier, broker)` upserts `ACTIVE` `ManagedPosition` rows and marks absent holdings `DISPOSED` (never deleted). Historical `as_of_date` checks `acquisition_date <= as_of_date < disposal_date`.
- **One writer per field (#2920, #2922)**: the snapshot import (`reconcile_positions`) writes the quantity, status, and `latest_snapshot_date` of a `ManagedPosition` (clearing `position.cost_basis` if a snapshot switches currency). Only `post_buy`, `post_sell`, and `POST /api/portfolio/trades` write `cost_basis`, `InvestmentLot` lots, `InvestmentTransaction` rows, and realized P&L.
- **Cost without full purchase coverage is empty (#2920, #2922)**: `ManagedPosition.cost_basis` is `NULL` until recorded purchases cover the open quantity. When `InvestmentTransaction` rows exist for a position, the holdings loaders compare net recorded BUY-less-SELL quantity against position/snapshot quantity and return `null` cost and unrealized P&L if open recorded quantity does not cover the position, and convert cost from the purchase `InvestmentTransaction.currency` rather than relabeling with a later snapshot currency. `get_portfolio_summary` and the performance schedule follow the same `null` rule when any active position lacks covered cost.
- **Read (`extension/{holdings,allocation,performance,performance_report}.py`)**: Computes XIRR/TWR/MWR, dividend yield, allocation, and FX-converted P&L via `pricing` (`PricingError` on missing rates). `calculate_time_weighted_return` (`start_value == 0`) and `calculate_dividend_yield` (`current_value == 0`) raise `InsufficientDataError`. `build_investment_performance_report_schedule` computes all holdings, metrics, and allocations in the requested schedule presentation currency. Use `Decimal`, never `float`.
